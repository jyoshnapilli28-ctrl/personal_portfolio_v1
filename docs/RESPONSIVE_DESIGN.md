# Responsive Design

Support: Large desktop, Desktop, Laptop, Tablet, Mobile.
Do not simply scale the desktop layout. Create intentional responsive compositions.

## Mobile Strategy
- Simplify complex visual compositions.
- Stack content vertically.
- Reduce unnecessary 3D complexity.
- Maintain hierarchy and keep typography readable.
- Preserve important animations.
- Make controls touch-friendly.

## Interactions
- Hover interactions must have usable alternatives on touch devices.
