# Animations

GSAP controls major animation behavior. Animations must be smooth, cinematic, intentional, responsive, and performance-conscious.

## Page Load
- Navigation reveal
- Hero typography reveal
- Portrait reveal
- Supporting visual reveal

## Scroll Animations
- Section reveals
- Text movement
- Image movement
- Parallax
- Depth transitions
- Project transitions
- Progressive storytelling

## Micro-Interactions
- Buttons
- Cards
- Navigation
- Links
- Project previews
- Form controls

## Principles
- Avoid unnecessary animation. Every animation must have a purpose.
- Respect reduced-motion preferences.
