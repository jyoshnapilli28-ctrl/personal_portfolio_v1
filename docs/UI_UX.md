# UI/UX Experience

The website is a visual storytelling experience.

## Section Breakdown

### 01 — NAVIGATION
- **Characteristics:** Dark environment, minimal navigation, small refined typography, clear links, rounded interaction elements, strong spacing, subtle hover effects.
- **Content:** Logo/name, links, active state, CTA, mobile menu.

### 02 — HERO
- **Purpose:** Primary visual focus communicating who I am, what I do, and what I am building.
- **Content:** Large typography, introduction, CTA, portrait/profile visual.
- **Visuals:** Layered composition, depth, perspective, optional 3D visual. The portrait is a major visual element.

### 03 — ABOUT / PROFILE
- **Purpose:** A digital identity/system profile.
- **Content:** Large portrait, "Hello, I'm..." typography, descriptive text, technology/role cards, status-style information, dark rounded panels.

### 04 — SKILLS / TECHNOLOGY
- **Purpose:** Showcase technical proficiency through System/Architecture Visuals (e.g., "Core Execution Root Map" with horizontal rounded cards).

### 05 — PROJECTS
- **Purpose:** Large visual compositions presenting high-quality case studies.
- **Content:** Title, description, category, tech, project image/UI screenshot, external links.
- **Visuals:** Perspective, layering, depth, rounded cards, hover movement, scroll interaction.

### 06 — JOURNEY / EXPERIENCE
- **Purpose:** Professional timeline and experience overview.

### 07 — ACHIEVEMENTS
- **Purpose:** Notable milestones.

### 08 — CONTACT
- **Purpose:** "Let's Build Something..." interface.
- **Content:** Name, email, message inputs, submit interaction on dark rounded UI panels.

### 09 — FOOTER
- **Purpose:** Final branding and links.
