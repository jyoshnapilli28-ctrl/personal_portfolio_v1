# Portfolio Icon Assets

This directory contains the optimized SVG icon set for the portfolio. All icons are built with a uniform `24x24` viewBox and use `currentColor` for seamless integration with the portfolio's color system (`text-ivory`, `text-champagne`, `text-muted`, etc.).
